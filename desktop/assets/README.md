SayIn 品牌图标来自用户提供并确认的 `../../assets/sayin-icons/B-field`，通过 `python scripts/sync_brand_assets.py` 原样同步。

- `sayin.ico`：Windows exe、主窗口及任务栏图标。
- `sayin-tray-dark.ico` / `sayin-tray-light.ico`：按系统任务栏明暗主题使用。
- `sayin-64.png`：桌面界面品牌图标。
- `brand-assets.json`：平台目标文件、原始路径及 SHA-256，便于核对来源。

界面中的操作图标仍为 Yue 内置 Tabler；`LICENSE.tabler` 保留其授权信息。F-yan 为未选用的源方案，不混用于产品。
