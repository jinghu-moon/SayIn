# 手机说话页与连接入口 Demo

日期：2026-11-13。设计参考：[手机说话页](sayin-mobile-speak.html)。桌面端行为依据：[接收页设计](sayin-receive-design.md)、[接收页重构](../29-desktop-receive-ui-refactor.md)。

2026-11-14 更新：原生落地情况见 [手机端重构](../34-android-speak-and-connection-refactor.md)。下文保留 Demo 评审时的范围说明；当前已实现原身份地址维护，仍无 mDNS 自动发现。

## 目标与边界

手机负责说话、编辑与发送；电脑在后台接收，输入当前光标。日常使用不需要先进入电脑界面处理文字。连接入口只负责解释当前状态并提供必要的恢复操作，不能成为每次发送的必经步骤。

本次只更新 HTML 参考设计，没有修改原生 Android 或 Windows 软件。识别、模型准备、扫描、批准和重连均为模拟，不访问麦克风、云服务或真实设备；演示时间不代表实际性能。页面右侧场景选择器与模拟批准按钮仅用于评审。

## 连接与接收分开

| 情况 | 顶栏 | 面板与操作 |
| --- | --- | --- |
| 首次连接 | 连接电脑 | 扫描电脑二维码为主操作，输入配对码为备选；两者都等待电脑明确批准 |
| 等待批准 | 等待批准 | 说明去电脑接收页批准，可取消本次请求 |
| 已连接、可发送 | 电脑名称 | 展示已连接与当前光标输入说明，无重复确认按钮 |
| 已配对、电脑离线 | 电脑离线 | 保存原配对，等待恢复；提供重新连接，帮助按需展开 |
| 电脑主动暂停 | 接收已暂停 | 明确连接正常，由电脑恢复接收，手机不提供越权恢复按钮 |
| 电脑需要核对 | 需在电脑核对 | 到目标软件核对上一条，再在电脑确认；不提供自动重发 |
| 网络、邀请或存储异常 | 对应原因 | 仅显示与当前问题相关的信息或操作 |

已连接时点击顶栏展开底部面板，不断开连接。关闭、遮罩、Escape 均可收起面板；不增加“知道了”按钮。电脑名过长在顶栏省略，面板内换行。网络地址等技术信息收进连接帮助，不要求用户先选择网卡或修改 Windows 网络分类。防火墙与设备间可达性仍可能影响实际连接。

## 草稿与恢复

- 离线或接收受阻时仍可说话与编辑，点击发送打开原因面板并保留草稿。
- 连接恢复、更新地址、关闭面板均不触发发送，也不自动补发旧文字。
- 暂停与待核对闸门在断线重连后保持；不能用“网络好了”替代用户在电脑上的明确操作。
- 演示中的“说完自动发送”默认关闭，只在可发送时的明确结束操作后生效。编辑、清空、重新录音、切换来源、打开连接面板或切换连接场景会取消尚未执行的延迟发送。
- 已配对时提供更新地址的设计，复用原身份，不要求重新扫码。当前原生 Android 仍使用已保存地址，没有实现此地址恢复界面或 mDNS；后续实现必须保持主机证书固定，地址变化不能替换可信主机身份。

## 底部状态

底部只显示识别状态与字数，连接状态由顶栏负责。

| 来源 | 文案 |
| --- | --- |
| 云端待机 | 豆包识别 · 音频上传云端 |
| 云端录音 | 正在通过豆包识别… |
| 本地首次准备 | 正在加载本地模型… → 模型已加载，正在预热… → 本地识别已就绪 |
| 本地录音 | 正在本机识别… |
| 输入法 | 使用输入法输入 |

准备期间禁用录音，准备完成不自动开启麦克风。实际软件应按引擎真实事件显示状态，不能用 Demo 定时器代替真实就绪判断。

## 本次验证

修改前的右上角按钮直接切换连接；修改后只展开状态面板。浏览器实际验证了首次扫码请求、短码校验、等待电脑批准、已连接不误断开、离线草稿保留、暂停/待核对跨重连保留、更新地址、12 种连接场景、显式发送与模型加载/预热/就绪。补充验证延迟自动发送的取消边界、键盘焦点循环与恢复、背景不可交互、320px/360px 窄屏、长电脑名、深色与减少动效。验证不覆盖真实网络、鉴权、原生模型加载和真实光标输入。
