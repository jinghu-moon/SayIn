连接电脑

此区域用于评审，不属于 App。扫描、批准、重连均为模拟；不会连接设备或发送文字。等待批准时，可先收起手机面板，再点这里的「模拟电脑批准」。

这版改了什么

  1. 麦克风成为主角。88 像素的大按钮放在屏幕下方正中，单手就能按；说话时变红并有扩散的圈。
  2. 连接状态收进顶栏。原来整行的“连接电脑”缩成一个小标签，显示连接与接收状态，点击展开面板；连接正常时不会误触断开，草稿区因此多出一大块。
  3. 识别方式贴近麦克风。本地、云端、输入法放在按钮正上方，选完就能直接说。
  4. 说完才亮起发送。说话与发送先后分明，说完后发送按钮会闪一下提示。
  5. 模型准备状态清晰。首次选择本地时，底部依次显示加载、预热、就绪；准备期间不会录音，完成后由你点按开始。再次切回本地无需重复准备。
  6. 草稿边说边出字。没确认的部分颜色较淡，随时可以点进去改，不用先点“编辑”。

连接入口

  1. 右上角是状态入口，点开面板查看原因和下一步；连接正常时不会断开。
  2. 首次扫码 / 配对码二选一，等待电脑明确批准；已有配对直接重连。
  3. 连接与接收分开：电脑暂停或待核对时仍显示已连接，只能去电脑恢复或核对。
  4. 连接恢复不清草稿、不自动发送、不解除电脑暂停，也不补发旧文字。
  5. 已配对但地址改变时，更新地址复用原身份。该能力是后续原生实现设计，当前 Android 尚未接入地址恢复。

状态文案

  1. 底部只保留当前识别状态与字数，连接状态由顶栏负责，不重复堆叠说明。
  2. 本地：正在加载本地模型… → 模型已加载，正在预热… → 本地识别已就绪。
  3. 云端：豆包识别 · 音频上传云端。输入法：使用输入法输入。
  4. 本页仅演示视觉与状态变化，加载、预热、识别均为模拟，不代表实机耗时或云端连通。

可以试的

  1. 未连接时也能说话、编辑；点发送打开连接面板，连接恢复后保留草稿，由你再次点发送。
  2. 打开“说完自动发送”，说完会直接发出。
  3. 切到“输入法”，麦克风会变成键盘，改用系统输入法的语音键盘。
