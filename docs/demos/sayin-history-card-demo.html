示例数据

示例数据，仅用于展示卡片结构；不连接真实记录、电脑或发送链路。

新的记录卡片

  • 一行状态：状态标签 + 时间固定在同一行，扫视时先看到“这条有没有成功”，时间对齐右上方。
  • 内容优先：文字最多 3 行；图片给 64dp 缩略图 + 尺寸/大小，不再把缩略图缩成小点、下面留大片空白。
  • 结果说明按需出现：已提交不重复解释；异常说明原因（暂存/待核对/暂无回执），不再每条都重复长说明。
  • 去向一行：执行时目标应用（图标 + 名称）；未识别时明确写“未识别目标应用”，不使用当前前台应用补全历史。
  • 复制直接可点，其余进 ⋮：「查看原文/查看图片」与「删除记录」收在卡片菜单里，图片可直接点缩略图；删除仅影响本机展示，需二次确认。
  • 状态色只用于状态：已提交绿、待处理黄、待核对红、已取消灰；不做大面积底色。

与桌面端卡片对齐

  • 同样的信息顺序：时间/状态 → 内容 → 去向 → 操作。
  • 桌面端显示完整图片和下载；手机端用缩略图 + 复制，尺寸/大小保留在缩略图旁。
  • 提交语义放入详情，卡片保留状态，避免用户以为目标框一定已显示。
