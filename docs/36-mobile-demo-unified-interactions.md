# 36 · 手机完整页与快捷卡统一交互

日期：2026-11-14。范围：用户修改后的 `refer/sayin-mobile-ui.html` 与 `refer/sayin-quick-entry.html`。本次更新参考 demo，不修改 Android/Windows 产品实现、不构建或安装应用。

## 统一方式

两份 HTML 分别默认进入完整说话页和快捷入口，共用同目录的 `sayin-mobile-demo.js`、`sayin-mobile-demo.css` 与 Yue token 快照。每份 demo 内都能切换完整页、快捷卡以及悬浮球/磁贴/通知，切换展示不创建第二个识别会话。

同一页内共用草稿、选区、识别方式、自动发送开关、连接状态、当前请求与记录。完整页保留说话、记录、连接、设置四页；快捷卡压缩展示，识别方式收进更多菜单，不把完整设置搬到卡片上。“在 SayIn 中编辑”直接切到当前会话的完整页。

两个独立浏览器标签页不同步状态；所有识别、配对、权限与送达均为当前页面内的模拟，没有真实麦克风、云服务、局域网请求、后台服务或持久化。

## 行为规则

| 阶段 | 统一操作与结果 |
| --- | --- |
| 空草稿 | 点麦克风开始说话，也可直接输入 |
| 有草稿 | 显示“继续说话”，按当前选区插入新识别内容 |
| 模型准备 | 本地按加载 → 预热 → 就绪展示；可放弃本次，取消后不延迟启动录音 |
| 正在录音 | 主按钮为“结束说话”；更多里的“放弃本次录音”恢复本轮开始前的原稿 |
| 结束说话 | 等识别最终结果，再进入待发送或倒计时；停顿不触发发送 |
| 发送中/电脑已接收 | 冻结当前请求文字，不能重复提交 |
| 没有回执 | 查询原请求，仍无结果时保留原请求与文字，不提供直接重发 |
| 输入结果不确定 | 展示“输入结果待核对”；关闭或收起保留文字和请求，用户核对与系统回执分别记录 |
| 明确未接受 | 保留文字，允许用户在处理原因后手动重发 |
| 已提交输入 | 显示实际已知目标或“目标未知”；不声称已验证目标输入框出现文字 |

自动发送统一命名为“说完自动发送”，默认关闭。用户明确结束说话、拿到最终识别结果、电脑可接收且当前说话界面可见时，才启动三秒倒计时。长短句、中文与英文使用同一规则，取消原快捷版的短中文启发式判断。

编辑区获得焦点、修改文字、继续录音、切换识别方式、打开更多/连接、收起、离开说话页、切换形态/入口或连接状态变化，取消本轮倒计时。收起与切换入口保留录音和草稿；通知提供结束说话与恢复当前会话的入口。界面不可见时结束录音不在后台启动发送倒计时。

离线、暂停、配对待批准都允许先说，草稿自动保留；删除冗余“先记下来”。连接恢复不自动发送旧文字。配对“等待电脑批准”只属于连接状态，“输入结果待核对”属于具体消息，彼此不混用。

## 原有问题与结果

| 修改前 | 修改后 |
| --- | --- |
| 完整页与快捷卡各自实现录音、发送和状态文案 | 同一脚本与说话组件，展示尺寸不同 |
| 完整页说完自动发送，快捷版按字数/英文决定是否发 | 同一开关和三秒倒计时，不按内容猜测用户意图 |
| “停止”与“结束说话”命名不一致 | 统一“结束说话”，定稿期间有状态提示 |
| 录音中取消本轮与清空全部的语义不清 | 放弃本次保留原稿，清空草稿独立且可撤销 |
| 已接收记录仍能直接重新发送 | 已接收记录仅查询，不重复提交 |
| 不确定结果点“知道了”清掉内容 | 收起/关闭保持原请求和文字，核对后显式处理 |
| 离线时同时提供继续说话、先记下来、连接电脑 | 自动保存草稿，只保留说话与连接入口 |
| 中性色与功能色为临时硬编码，更多图标为横向三点 | 共用 Yue neutral/feedback token，主题色 #1f75db，Tabler dots-vertical |
| 快捷版没有与完整页一致的适配预览 | 两形态都可组合预览 320/360/390 宽、字号、长名称、键盘、明暗主题 |

## 资产与验证

`sayin-demo-tokens.css` 是 Yue `packages/tokens/src/primitives/color.css` 中 neutral/状态色阶以及 `semantics/feedback.css` 的本地快照，来源摘要见 `sayin-demo-tokens.json`。普通界面使用 neutral，功能状态使用 Yue 的 success/warning/error，品牌色固定为用户指定的 #1f75db。无需依赖相邻项目的绝对路径或联网加载。

功能图标采用仓库现有 Tabler v3.51.0 的固定提交资源；缺少的 dots-vertical/search/player-play 从同一提交补齐，路径与 SVG SHA-256 见 `sayin-demo-icons.json`，MIT 许可随同保留。B-field 品牌图案保持原有形状与颜色。两 HTML 需与同目录公共 CSS/JS/资产清单一起使用。

验证基线保存在 `docs/research/36-demo-before`，保留本轮修改前的两份 HTML。检查覆盖两个入口默认状态、录音与草稿取消、跨形态/入口恢复、三秒自动发送与取消、离线恢复、未知请求查询、人工核对记录、配对批准、本地模型状态、权限/空录音，以及窄屏/大字号/键盘/长名称/明暗主题组合。图标和样式调整后重新执行相关浏览器检查，最终执行结果见下方 JSON，不将 demo 检查等同于原生手机功能验收。
