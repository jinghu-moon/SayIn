# 23 · 桌面侧边栏布局修复

日期：2026-11-13。

## 问题与原因

用户截图中的全局导航紧贴顶部分隔线，图标与文字偏向列中央，选中状态仅在远离内容的右边缘显示竖线。原因是应用将 `YueTabs` 的 Left placement 用作主侧边栏：该组件保留标签页的头部布局与边缘指示条，不符合本应用的侧边导航呈现。

修改前新增几何回归，实际失败于 `navigation needs a top inset`，建立了可重复的失败基线。

## 修改

- 使用 Yue 已有 GPUI Base 的 `TabsController`、`Tabs`、`Tab`、`TabPanel` 组合应用导航。框架继续拥有鼠标激活、方向键、Home/End、roving focus 和无障碍语义，Shell 拥有当前页面和布局；没有修改外部 Yue 库。
- 导航列增加统一内边距和行间距，四项使用相同整行宽度与高度，图标和文字沿固定左边缘排列；点击行尾也能切换页面。
- 选中项采用 neutral 圆角底色、品牌色 `#1f75db` 文字/Tabler 图标与字重，不再绘制边缘竖线。hover、pressed 和键盘焦点保留独立反馈。
- 窗口变窄时调整导航列宽度，内容区域占剩余空间，各页继续独立滚动。只挂载当前活动页面，保留现有设置、历史查询和弹窗状态。
- 导航组件替换后曾使主内容继承行距发生变化，原有设置保存失败重试回归发现了按钮位置变化。已显式保留原有主内容行距并重新通过该回归。

## 验证

- 新几何/交互回归覆盖简体中文和 English、明暗主题、720/1000 两种窗口宽度，核对顶部留白、行宽、边距、间距、行尾点击、方向键及 Home 切换。
- 完整 `cargo test --workspace --all-targets --locked`：94 项通过；Clippy `-D warnings`、工作区构建和包限定格式检查通过。
- `python scripts/check_i18n.py`、`python scripts/check_desktop_dependencies.py` 通过，外部 Yue 源码摘要未变。
- `verify_desktop_shell` 生成 50 张实际原生渲染图，覆盖双语、明暗主题、两种尺寸和各页面/弹窗；已查看中文浅色接收页和英文深色最小窗口设置页，确认侧边栏对齐与选中底色正确。
- 渲染例程使用独立数据及假历史，不访问生产账本、不监听真实手机或执行输入。该轮布局验证不等同于重新测试真实手机落字或延迟性能。
