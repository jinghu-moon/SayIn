# Windows 公用网络会话授权实施记录

日期：2026-11-12。

## 目标与根因

用户希望保留 Windows「公用网络」分类，并正常使用手机配对与接收。修改前，Network List Manager 枚举阶段只留下 Private/Domain 网卡，网络服务启动和周期监测也只认可这两类；仅改界面提示或列出公用 IP 都不能解决完整调用链的问题。

本次统一修改发现模型、会话授权、服务启动与周期监测。没有修改系统网络分类或防火墙规则，也没有增加全局 `allow_public` 偏好。二维码/8 位代码二选一、CPace、固定主机证书 TLS 1.3、本地批准、连接/握手限制及持久去重继续使用原有实现。Android 无需更新。

## 当前行为

1. 只列出 Windows 已连接、运行中的非 loopback IPv4 接口；无有效网络配置文件、链路本地、未指定或多播地址不提供为产品选项。界面显示网卡名称、IP 与公用/专用/域类别。不会根据 RFC1918 地址形状推断可信。
2. 用户明确选择一个接口。专用/域网络可直接开始配对；公用网络默认禁用「开始配对」，需要勾选「本次会话允许所选公用网络」。多配置文件网卡中只要存在 Public 就要求此确认。
3. 授权绑定 **网卡 GUID + IPv4 + Windows 网络 GUID/类别集合**。网卡名称仅用于显示，不是安全身份；改名不影响授权。授权不写入设置或账本，不传给手机。
4. 切换接口、刷新列表、启动失败或退出清除授权；返回原接口不会恢复之前的勾选。点击开始时重新向 Windows 核对完整授权范围，之后才绑定一个明确地址。优先 7788，冲突时使用系统分配端口并再次核对；不监听 `0.0.0.0`。
5. 监听期间约每 2 秒核对范围，查询超时上限 3 秒。网卡/IP/网络 GUID/类别集合变化，接口消失或查询失败/超时，会立即关闭输入闸门、发出服务停止信号，继而关闭配对窗口并断开连接。周期检测和 OS 状态采样存在时间窗口，不声称网络切换与输入原子联动；短暂变化若完全发生在采样间隔内也可能不可见。
6. 公用网络授权与手机批准是两个不同步骤：前者只准许当前监听范围；手机仍须经加密配对并由电脑本地批准。重启不会遗留公用网络授权，已有手机身份也不会绕过此范围检查。
7. Windows 防火墙仍独立生效。若出现系统请求，只应允许该应用使用所选可信网络对应的类型。应用不自动创建规则，也不要求关闭防火墙；公用类型下未获得入站许可时仍可能连接超时。

## 代码位置

| 位置 | 职责 |
| --- | --- |
| `desktop/crates/transport/src/interfaces.rs` | Network List Manager 配置文件、GUID 集合、接口枚举、精确范围授权与校验 |
| `desktop/crates/transport/src/server.rs` | 分离 `start_on_network` 与仅接受 loopback 的 `start_loopback`；服务内部核对授权、后台持续监测 |
| `desktop/src/reception.rs` | `NetworkSelection` 同时持有接口、选择和授权，避免切换时借用旧授权 |
| `desktop/src/shell.rs` | Yue 单选接口、会话许可勾选框、禁用状态与防火墙提示 |
| `desktop/locales/{en,zh-Hans}.ftl` | 中英文本地化，沿用 neutral 与既有品牌主题 |
| `desktop/crates/transport/examples/network_policy_probe.rs` | 独立本机诊断：拒绝输入、关闭配对窗口、临时端口与数据目录，不批准手机 |

Loopback 测试入口严格拒绝 LAN/通配地址，不能作为产品公用网络旁路。调用者伪造/修改发现元数据不会绕过启动时对真实 OS 快照的核对。

## 用户真机测试步骤

1. 从项目根目录运行 `.\scripts\desktop.ps1`，打开新版本。Windows 网络类型保持「公用」。让手机 Wi-Fi 与电脑接入同一个允许设备互通的局域网。
2. 电脑选择「配对手机…」，选择 **以太网 · `192.168.71.6` · 公用网络**（这是本次核查值，地址变化时以界面为准），不要选 FlClash 虚拟网卡。
3. 确认未勾选时「开始配对」不可用，再勾选「本次会话允许所选公用网络」，点击「开始配对」。若 Windows 防火墙询问，允许当前应用在所选公用类型接收入站；无需更改网络分类或关闭防火墙。
4. 手机扫描电脑二维码，**或**手工输入电脑显示的地址、端口与 8 位配对码，二选一。随后在电脑本地批准该手机。以界面端口为准，未必始终为 7788。
5. 打开普通权限文本编辑器，电脑点击「锁定窗口…」，在 3 秒内切到编辑器；锁定完成后回电脑选择「恢复输入」。手机发送唯一短句（含中文/英文/emoji），确认只出现一次、无自动 Enter，并查看手机回执。当前测试文字可从手机手工输入，语音识别仍为后续功能。
6. 在电脑暂停后，手机发送另一句，确认目标不落字。重连后检查收据，不要对未知/不确定结果盲目重复发送。
7. 检查授权范围：退出重开，公用许可应未勾选；监听期间断开所选网络，电脑应停止监听并暂停。重新接入后重新选择并授权。不要为验收特意修改 Windows 网络分类。

如果步骤 4 超时，先核对实际接口/IP/端口与同网情况，再检查所选 Public profile 下当前 exe 的防火墙入站许可，以及路由器客户端隔离。应用内勾选不能越过这些系统/网络策略。真实扫码、Wi-Fi 入站、物理网络切换与真实目标落字仍需用户完成上述验收；本次不报告已达到的输入延迟目标。
