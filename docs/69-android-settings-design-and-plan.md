# SayIn 手机端设置界面设计与实施计划

日期：2026-11-16。状态：设计与待实施计划，不是功能完成记录。

核对基线：`main 5189896ca51d57a5126d48a7d39b15c29040c2e4`。本机同时存在连接状态按钮等未提交改动；本文不把这些改动视为已发布基线，不修改或纳入其他任务的代码。

## 1. 目标与范围

设置页用于调整长期使用偏好、配置识别服务、管理快捷入口，以及查看必要的数据和应用信息。正常说话、编辑、发送和处理单条记录，仍在对应业务页面完成。

本设计遵循第一性原理与奥卡姆剃刀：只有用户确实需要决定的行为才提供配置；自动发现、安全认证、流式处理等正确性要求直接内置，不改成用户选项。开发期可以重构页面、导航和状态归属，不为旧界面增加适配层，但必须保留当前用户身份、草稿、历史与 Outbox，并建立修改前后的验证。

本轮用户已确认：允许为确定要建设、尚未实现的功能预留置灰项；预留项不可点击，并清楚说明“开发中”。功能未实现和现有功能尚未接入新设置页必须分开记录。

本文覆盖手机设置一级页、二级配置页、少量三级编辑/详情页、Miuix 组件、布局、状态、默认值、双端配合、实施阶段与测试。本文不授权直接实现所有预留能力；当前重构与后续功能建设分别验收。

## 3. 页面树与层级

一级页是底部导航的“设置”。二级页使用应用内全屏页面；二级页面的返回回到设置，三级页面返回原二级页及原滚动位置。最多三级，不再嵌套第四级。系统权限页和浏览器属于外部系统界面，不算应用内配置层级。

```text
设置 [一级，底部导航根页]
├─ 语音与输入
│  ├─ 语音识别 → 语音识别 [二级]
│  │  ├─ 识别方式：离线识别 / 云端识别 [行内下拉]
│  │  ├─ 离线模型 [状态行，无多模型选择]
│  │  ├─ 云端服务 → 豆包语音配置 [三级]
│  │  └─ 热词 → 热词编辑 [三级]
│  ├─ 说完自动发送 [行内开关]
│  └─ 翻译 → 翻译与模型 [二级]
├─ 快捷入口
│  ├─ 悬浮球 [行内开关，按需系统授权]
│  ├─ 控制中心快捷入口 [系统添加磁贴；旧系统为说明弹层]
│  └─ 后台运行帮助 → 后台运行帮助 [二级]
├─ 使用体验
│  ├─ 外观 [行内下拉，未实现时置灰]
│  ├─ 应用语言 [行内下拉]
│  └─ 使用时保持亮屏 [行内开关]
├─ 数据与隐私
│  ├─ 存储管理 → 存储管理 [二级，未实现前入口置灰]
│  ├─ 剪贴板增强 → 剪贴板增强 [二级]
│  └─ 隐私说明 → 隐私说明 [二级]
└─ 关于
   └─ 关于 SayIn → 关于 SayIn [二级]
      ├─ 使用帮助 → 使用帮助 [三级]
      ├─ 项目主页 [浏览器]
      ├─ 开源许可 → 开源许可 [三级，列表及行内展开]
      └─ 诊断信息 → 诊断信息 [三级，未实现前入口置灰]
```

“热词”页是语音识别页的直接子页，不从豆包配置页再次进入，避免第四级。它仍编辑同一份豆包配置，不创建独立热词数据库。选择语言或外观不打开只有两三项的全屏页面。

二/三级页遮盖底部导航，以固定返回路径为主；根设置页保留四项底部导航。快捷卡中的“设置”跳转完整应用的对应页面，不把三级表单塞进浮动快捷卡。设置不创建第二个 SpeakSession。

```text
│ 说话       记录      连接    设置 │  固定底部导航
└──────────────────────────────────┘
```

线框中的符号只表达图标位置；实际使用项目 Tabler 矢量，不使用 Emoji 或另引入一套图标包。

- 页面框架用 Miuix `Scaffold`、`SmallTopAppBar`；滚动内容用 Compose `LazyColumn`，卡片用 Miuix `Card`。通用布局、导航和生命周期使用 Compose/Android 原语，不为“全 Miuix”重复造轮子。
- 背景使用现有 Yue neutral canvas，卡片用 surface；品牌色保持 `#1f75db`。使用现有 `VoiceLinkTheme` 和 Yue 功能色，不引入默认 Monet 或彩虹设置图标。
- 手机单列，左右 16dp；内容最大宽度 600dp 居中。平板和横屏仍单列，不把配置项分成会改变阅读顺序的多列。
- 分组间距 20dp，标题下距 8dp；卡片圆角 20dp，采用接近零的外层 `insideMargin`，让 Preference 行负责行内间距，避免双重 padding。
- 行内左右约 16dp；无摘要行自然高度至少 56dp，有摘要行通常 72dp 起，大字号按内容增长，不固定高度裁切。所有可交互目标至少 48×48dp。
- 一级每行预留一致的 24dp 图标列、与标题相隔 12dp；用简洁单色图标，开关行与入口行对齐。二/三级页的每个输入字段不重复加图标。
- 标题建议 16sp，摘要/当前值 13sp，组标题 13sp。优先使用 Miuix 对应文字样式；不得用屏幕像素抵消系统字体缩放。
- 短当前值可放在右侧，长值或说明移到标题下方。窄屏/英文/大字号时不得挤没标题、开关或箭头；摘要允许换行，不把关键信息只放在省略号里。
- 分组靠留白和卡片区分，默认不每行加粗分割线，也不叠加重阴影/描边。禁用项使用组件禁用色，同时保留“开发中”可读性。
- 顶栏和底部导航固定，内容滚动；列表 bottom contentPadding 包含导航和系统 inset，不让最后一项被底栏盖住。

### 5.2 二/三级页通用布局

```text
┌──────────────────────────────────┐
│ ‹ 页面标题                 [保存]│  返回；仅编辑页需要保存
├──────────────────────────────────┤
│ 分组卡 / 状态 / 表单              │
│                                  │  正文可滚动
│ 必要的帮助与错误说明              │
├──────────────────────────────────┤
│ [下载 / 验证服务等页面主操作]     │  只有确有主操作时才显示
└──────────────────────────────────┘
```

二级页不显示连接胶囊和底部四项导航。简单偏好即改即生效，不设置统一“保存全部”。只有凭据、热词等编辑事务才有“保存”。每页只保留一个保存入口，不能顶栏和底部重复。

IME 弹出时使用系统 inset 和内容滚动保证当前字段可见。固定操作区独立于正文高度，不被列表挤出；必要时随 IME 上移。极小横屏允许主操作纳入滚动正文，确保可到达，不用固定大卡片挤掉输入框。

模态确认优先 Miuix `WindowDialog`；简单选项用 `WindowDropdownPreference`；已有 `OverlayBottomSheet` 仅保留给说话页就地模型准备等短流程，必须挂载正确 Miuix 宿主。弹层有界高度、内部滚动、48dp 关闭热区、返回键和焦点恢复。复杂表单不用层层 BottomSheet。

## 6. 二级语音识别与三级配置

### 6.1 语音识别 [二级]

| ID | 项目 | 组件 | 值与行为 | 初轮状态 |
| --- | --- | --- | --- | --- |
| R01 | 识别方式 | `TabRowWithContour` | 离线识别 / 云端识别；读取当前统一会话来源，不是把 Keyboard 当引擎 | 可用，迁入统一会话 |
| R02 | 离线模型 | `BasicComponent`，准备时 `CircularProgressIndicator` | 仅离线识别时显示；真实模型名称/就绪、加载、预热、失败；没有字节总量时不用假百分比 | 状态展示可用；管理动作按实际能力 |
| R03 | 云端服务 | `ArrowPreference` | 仅云端识别时显示；摘要“千问 · 已配置/未配置/配置读取异常”；进入三级云端配置 | 可用，迁入 |
| R04 | 热词 | `ArrowPreference` | 仅云端识别时显示；摘要“N 个”；进入三级编辑。离线时说明“用于云端识别”，不承诺离线注入 | 云配置可读且已存在时可编辑；否则显示“请先配置云端服务” |

R01 是唯一引擎选择入口，页面内容随选择切换：离线只显示离线模型，云端只显示云端服务与热词，不再把另一引擎的配置常驻在下方。切换 R01 只改识别来源，不开麦、不启动云请求、不发送草稿、不重置草稿；需要修改云端凭据时切到云端识别即可，配置动作本身不会上传音频或发送当前草稿。录音、收尾、翻译、冻结请求及待核对等会话状态按真实业务门禁禁用修改，并写明原因，不延迟排队在用户离页后偷偷切换。键盘状态下显示最近语音引擎，选择新引擎的生效过程要复用统一方法，不直接改 preference 绕过会话。

本页不设“模型预热”“流式输出”“TLS”“实时字幕”“CPU 线程数”开关。预热是引擎职责，真实加载完成与失败在说话页及本页状态展示。

| C08 | 清除凭据 | 低强调 `TextButton` + `WindowDialog` | 确认删除此云配置及其中的热词；不删除配对、草稿或历史，不自动改用另一引擎 |
| C09 | 获取凭据 / 配置帮助 | `ArrowPreference` | 打开确定的官方帮助地址；离页行为按未保存规则处理 |

字段原有限制从 `CloudConfiguration` 复用，不在 UI 定义第二套规则。当前凭据各最多 4096 字符且满足已有字符约束；错误就地显示，不能只让按钮无解释地变灰。

编辑使用内存缓冲；切换鉴权方式不能立即清除持久凭据，只有显式保存替换。未保存的替代方式敏感字段离页丢弃；切换前若会丢失编辑则明确确认。密钥不进 `rememberSaveable`、SavedState、日志、分析、剪贴板或通用诊断对象；页面不主动申请剪贴板读取。

服务验证旁固定短说明：“将向豆包发送约 1 秒静音，可能消耗额度，不使用麦克风。”打开页面、切换语言、保存、回到前台均不自动验证。测试只证明服务连通/鉴权，不证明热词生效或真实识别准确率。不把用户进入设置视为付费测试授权。

返回、系统返回、跳外部帮助遇到未保存改动时使用同一个 Miuix 确认框：“放弃未保存的修改？”选项“继续编辑”“放弃修改”。保存期间阻止重复提交；页面退出的任务结果仍按配置修订正确归属，不能覆盖更晚的新配置。

录音/云请求使用其开始时的配置快照；第一轮简化为这些任务期间禁止保存、清除与服务验证，确保不替换在用资源。不阻止用户查看说明。

### 6.3 热词编辑 [三级]

- 使用多行 Miuix `TextField`，每行一个词；顶栏“保存”，下方显示词条数量和总字符计数。
- 复用现有限制：最多 20 个去重词条、总长度最多 80 个 Kotlin 字符、单词条不超过 40、禁止控制字符；不把别的项目“100 条”能力搬进 SayIn。多语言计数显示要与真实校验完全一致，不谎称是 Unicode 码点限制。
- 读取和保存都基于同一 `CloudSettings` 配置及修订。热词保存保留当前凭据；期间凭据发生更改则重取/提示冲突，不用旧副本覆盖新密钥。
- 未配置云凭据时一级下的 R04 显示具体前置条件，不用“开发中”；跳转配置入口由同页的 R03 提供。
- 保存空内容表示清空热词；清除云凭据时一并清除热词的影响必须在 C08 确认框里明示。
- 不增加“启用热词”冗余开关；列表非空即按当前支持的云协议发送。离线不支持热词，不能展示为已经生效。

## 8. 快捷入口与二级后台运行帮助

### 8.1 悬浮球与系统快捷入口

- 悬浮球开关展示实际状态与用户意图的有效交集；请求系统授权尚未成功时不能先显示为已开启。可显示行内忙碌指示，取消或拒绝后说明原因，不循环弹权限。
- 通知、悬浮窗等权限分别按当前真实启动要求检查，不能把拒绝任意权限错误地等同于全部功能不可用；从系统返回重新读取实际权限与服务状态。
- 关闭悬浮球只停止该入口，不取消已开始录音、不清草稿、不关闭模块采集。失败要如实显示，不能靠偏好已写入伪装成功。
- “控制中心快捷入口”是动作，不是开关。系统请求接受不等于已能可靠查询磁贴安装状态；不能硬编码“已添加”。低版本展示手动添加说明，不标“开发中”。
- 不因为打开设置自动申请通知、悬浮窗、局域网或麦克风权限。

## 9. 使用体验

### 9.1 外观预留

首轮使用 `WindowDropdownPreference(enabled=false)`，标题“外观”，摘要“跟随系统 · 外观选择开发中”。选中值只表示当前真实跟随系统，不预写一个无效的“浅色”偏好。

未来启用后选项为“跟随系统 / 浅色 / 深色”，默认跟随系统。完整页、快捷卡、弹层与模型准备页使用同一来源，切换不重建业务会话、不停止录音、不清草稿、不重连或发送。没有完成这组验证前保持置灰。

### 9.2 应用语言

直接下拉“跟随系统 / 简体中文 / English”，继续用 AppCompat `AppLanguages` 作为唯一来源；不得另写一个语言 preference。配置变化后展示真实选择，兼顾入口页与二级页返回恢复。

切换语言不改变识别语言、用户正文、热词、译文、Outbox 或请求 ID；不能因为 Activity 重建创建第二录音/重复提交。所有“开发中”、忙碌、错误及无障碍文案也要有完整 en / zh-Hans 资源。

### 9.3 保持亮屏

沿用现有 `keep_awake`，默认关闭。完整应用或快捷卡窗口可见时按偏好生效；不可见/销毁恢复窗口之前的标志，不设置全局设备常亮或 WakeLock。悬浮球本身、模块采集和空闲后台不因此常亮。一级摘要不写“录音时常亮”，除非后续明确改变当前窗口级语义。

| S02 | 翻译模型 | `BasicComponent` + 受控动作 | 复用模型所有者安全删除，与翻译页操作一致；不是删除全部 files 目录 |

模型正用于翻译/加载、图片正用于上传/复制/预览时禁用对应清理，或者等待所有者显式释放；不能先删除再让运行任务报错。统计与清理不在主线程递归扫描。系统权限、云凭据不属于“缓存”。

### 10.2 剪贴板增强 [二级]

| ID | 项目 | 组件 | 当前可做与限制 |
| --- | --- | --- | --- |
| H01 | 普通模式说明 | `BasicComponent` | 说明 Android 限制：普通模式只取当前可访问的一条剪贴板，不伪装系统历史 |
| H02 | 模块说明 | `BasicComponent` | 独立采集、敏感/锁屏门禁、本机加密保存；采集由模块管理器明确控制 |
| H03 | 检查模块状态 | `BasicComponent` 可点击行或 `TextButton` | 用户显式操作才执行现有有界桥接；不在一级进入时自动 LIST，不申请 su |
| H04 | 检查结果 | 只读 `BasicComponent` | 仅使用实际可知结果：连接可用/暂不可用、`capture_ready` 就绪/未就绪；显示本次检查时间 |
| H05 | 配置说明 | `ArrowPreference` 或直接页内说明 | 指引到用户自己的模块管理器 Action；不依赖一个固定 Magisk/KernelSU 包名，不承诺自动打开 |
| H06 | 采集控制 | 禁用 `ArrowPreference` | “开发中 · 当前请在模块管理器操作”；无可用启停协议前始终不可点击，不展示无法确认的布尔开关值 |

H06 是唯一明确预留的模块控制项。当前 `capture_ready=false` 可能来自关闭、锁屏、初始化或不支持，不能据此写“已关闭”，也不能由 socket 不通认定“未安装”。当前固定采用不带布尔值的禁用入口，避免灰色关闭开关冒充真实 enabled；未来确有受鉴权的启停与状态协议后，再按明确控制粒度决定是否替换为 `SwitchPreference`。

现有协议没有不带历史预览的专用 STATUS，H03 若复用 LIST，仅解析检查所需字段，不展示/记录条目预览，不保存列表；说明这是访问模块接口，不声称零数据读取。未来若需要完整版本/安装/启停状态，先补无正文 STATUS 与鉴权测试，再启用对应控件，不能随意放宽私有文件权限。

设置页不展示剪贴板正文、不新增常驻轮询、不因进入而开启采集或保活。常用语和剪贴板的编辑、排序、复制、粘贴与清空仍在现有辅助输入面板，避免重复管理。

### 10.3 隐私说明 [二级]

分三张轻量卡片，使用 `BasicComponent` 或 Miuix `Text`：

1. 本机数据：草稿、历史、图片和凭据按现有加密机制保存；删除展示历史与内部请求账本的区别。
2. 跨设备：文字与图片通过已配对电脑的固定证书通道发送；发现只找地址，不建立新信任；应用提示不保证输入框可用。
3. 云端处理：云识别会向配置的服务上传音频和支持的热词；本地识别和本地翻译的推理在本机，模型下载仍需网络。选择“本地翻译”不代表云识别音频也不上传。

不写“所有数据都不离开手机”之类绝对文案。说明不带同意开关，不因浏览而请求权限。

## 12. 可用、开发中、受限与忙碌状态

| 状态 | 展示 | 是否可操作 | 必须避免 |
| --- | --- | --- | --- |
| 已实现且可用 | 正常颜色、真实值 | 可用，业务门禁仍生效 | 从静态页面配置伪造真实状态 |
| 功能未实现 | Miuix `enabled=false`；同一行摘要“开发中” | 不可点击、不弹菜单、不导航、不触发任务 | 点击弹“敬请期待”、进入空页、假下载或假进度 |
| 功能已有、配置入口未实现 | 只把新增入口标为“配置入口开发中” | 旧入口与已有功能保持可用 | 把整个翻译/云识别说成未实现，删掉旧功能后拿置灰项替代 |
| 前置条件不满足 | 标题可读，摘要给具体原因 | 不能执行的动作禁用，解释/授权入口可用 | 一律标“开发中”，让用户不知道如何恢复 |
| 操作进行中 | 行内真实进度，仅锁定相关控件 | 无冲突项可用，可取消的任务保留取消 | 一个保存动作把整个设置页持续变成加载动画 |
| 操作失败 | 原行/表单附近显示具体错误，保留输入与原有效值 | 可重试的给明确操作 | 自动清数据、自动切云、本地回退、反复弹窗 |

首轮固定预留：一级外观、一级存储管理、模型占用统计/安全删除中的未实现部分、模块 App 采集控制、诊断信息。O04 只有真实清单完成才启用。不是所有设置都变成 roadmap；尚未确定的多供应商、目标语言、AI 润色、语音指令、跨端同步、账号系统不占位。

禁用项仍保留无障碍读取：项目名、原因、不可用语义；不整行大幅 alpha 导致文字不可读。不应提供可执行的 onClick/自定义语义动作。开关无法提供可信当前值时，不把灰色关闭样式当作真实状态，应改为无布尔值的禁用说明行。

权限从系统设置返回重新检查；模块状态按本次检查结果显示并允许过期，不拿旧快照声称持续在线。页面打开和返回不弹无关 toast、不重复加载整页。

| 修改引擎/热词/云配置 | 复用同一会话与配置来源，任务期间按门禁限制 | 不创建第二录音，不重启已提交请求，不用新 ID 重发 |
| 修改外观/应用语言 | 只改变展示；已有录音按会话生命周期继续 | 不清草稿、不改变文本/译文、不重连或提交 |
| 开启快捷入口 | 仅启用唤起入口，保留同一 SpeakSession | 不开麦、不自动发送、不因此维持空闲后台发现 |
| 电脑暂停/未选中/待核对 | 设置页不重复连接控制，引导现有连接页/面板 | 恢复接收、选择活动手机、核对不确定结果仍在电脑完成 |
| 地址变化 | 无设置项，既有保存地址优先和有界发现继续 | 固定完整证书/身份/令牌不变，发现失败保留手动维护入口 |
| 存储清理 | 只操作已确认安全资源 | 不删除身份、收据、pending ledger，不解除 uncertain，不释放 held |
| 模块说明/检查 | 显式有界访问，仍是普通 App | 不申请 su、不修改模块采集偏好、不常驻保活 |

设置页不增加电脑端协议或按钮；纯 UI 重组不应要求电脑更新。若后续诊断/模块 STATUS/状态原因需要改公共接口，另行明确协议与双端测试，不能藏在“设置重构”内。

顶栏连接入口仅保留在说话业务入口，设置页右侧留空；连接页集中展示连接状态，记录页按请求展示状态。后台或切页按当前连接需求生命周期处理，不承诺“网络一恢复，无论 App 是否有连接需求都自动常驻连接”。

## 14. 状态、存储与代码组织

建议新增 `ui/settings/` 管理页面和路由，把 `VoiceLinkScreens.kt` 中的 SettingsPage 拆出，避免继续在根页面堆配置。首次实施按真实规模决定类和文件数量，不引入动态插件式配置系统或通用表单 DSL。

| 数据 | 唯一来源 / 所有者 | UI 的职责 |
| --- | --- | --- |
| 语音来源、最近语音引擎、自动发送 | Application 共享 `SpeakSession` 与现有 presentation 偏好 | 观察并调用已有受控操作，不直接写同名值 |
| 亮屏、未来外观 | 已有 presentation 偏好；按需提取小型共享所有者 | 窗口实际应用与偏好一致；不要同时建立 DataStore 第二来源 |
| 应用语言 | AppCompat `AppLanguages` | 只调用系统语言入口 |
| 云凭据与热词 | `CloudSettings`、`CloudConfigurationStore` | 配置编辑有草稿、有显式保存；按修订防旧任务覆盖 |
| 模型与推理/下载 | 现有翻译/识别所有者 | 状态可观察，任务不由每个页面各建一份 |
| 悬浮球 | `QuickEntryService`、现有偏好、系统权限 | 区分用户意图与实际启用状态 |
| 系统授权 | Android 系统 | 页面返回时刷新，无永久伪缓存 |
| 模块检查 | 现有 `RootClipboardAccess`，按需有界 | 不在 ViewModel 无限轮询，不保存历史正文 |
| 导航/滚动/非敏感 UI 状态 | 设置路由和页面状态 | 恢复页栈/滚动；敏感字段不得放 saved state |

默认值优先继承当前有效偏好。本设计不要求兼容旧 UI，但不得以开发期为由清用户数据或回退重配对；旧卡片删除后，原业务所有者继续存在。禁止先建立新的偏好源，再靠双向同步掩盖重复所有权。

页面加载采用局部状态：云配置读取只影响云相关行，模块检查只影响该状态行，空间统计只影响对应资源。打开更多菜单或点击纯展示项不能触发全页初始化。

## 15. 实施计划与阶段交付

### 阶段 0：设计与能力清单（本文）

### 阶段 1：Miuix 设置骨架与导航

- 提取 `ui/settings`，一级 5 组 13 项，建立二/三级路由、返回与滚动恢复。

### 阶段 2：现有配置完整迁入

- 用统一会话接好引擎与自动发送；迁入语言、亮屏、悬浮球、系统磁贴。

### 阶段 3：模型入口、帮助与信息页

- 复用现有翻译准备流程，新增二级管理入口；尚未实现的统计/删除保持明确禁用。

### 阶段 4：整体回归与交付

- 执行本设计全部状态矩阵，补升级前后对比，检查第一/二/三级页面的中文/英文、主题、大字号、返回、输入法与可达性。

- 交付更新的设计状态、实施记录、脱敏验证摘要、APK 摘要和安装说明。用户负责真机观感；未授权时不替换日常安装或读取用户内容，不截图验收替代用户审查。
- 验收：预留项仍清楚禁用，不把它们记为实现完成；已有能力都已迁入并通过检查。提交推送。
